About Sync Operations

The sync system compares release files with the database to identify differences. You can choose which version to keep for each conflict, or skip items you're unsure about.

Common workflows:

  • After editing release files: Use sync to import new entries and update changed data.
  • After database updates: Export changes back to release files to keep them current.
  • Quality assurance: Review differences to catch inconsistencies or errors.
