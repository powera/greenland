Spelling Variants
What is a spelling variant?

The same word written differently — "gray" ↔ "grey", "doughnut" ↔ "donut". Each variant carries its own full set of forms ("grey" → "greyer", "greyest"), which is why it is listed separately from both synonyms (different words) and inflections (different forms of this spelling).
