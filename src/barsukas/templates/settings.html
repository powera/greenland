Sync Difficulty Levels from Release Data

Update difficulty levels in the database from the golden release data (data/release/lemmas/).

This is useful after editing difficulty levels in the release JSONL files and wanting to apply those changes to the running database.

How it works:
  • Reads all *.jsonl files from data/release/lemmas/**
  • Matches GUIDs between release data and database lemmas
  • Updates difficulty_level where values differ
  • Reports statistics on changes made

Restart Barsukas

Gracefully restart the Barsukas process to:

  • Apply environment variable changes (e.g., switching storage backends)
  • Reload Python code changes
  • Clear memory and start fresh
The restart process will wait for all in-flight HTTP requests to complete (including long-running LLM queries) before restarting. No timeout is applied.
