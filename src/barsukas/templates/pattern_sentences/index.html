 About Pattern Sentences

        

        

            

                Pattern sentences are simple, templated sentences designed for language learning.
                Each pattern has fixed structure with slots that are filled with vocabulary words
                from the database.
            

            

                The new two-step workflow:
            

            
    
                
  1. Generate Candidates: Creates all possible sentence combinations from patterns with mechanical English templates (e.g., "I have 12 ring").
    2. 
                
  2. Submit Batch Translation: Sends untranslated candidates to OpenAI Batch API for translation into target languages, including grammatically corrected English.
    3. 
            

            

                Benefits of this approach:
            

            
    
                
  • Generates ALL possible combinations (cartesian product) for comprehensive coverage
    • 
                
  • Cost-effective: Batch API provides 50% discount on translation costs
    • 
                
  • Separates sentence generation from translation for better control
    • 
                
  • Corrects English grammar automatically (e.g., "I have 12 ring" → "I have 12 rings")
    • 
                
  • Links sentences to their constituent words via GUIDs for difficulty tracking
