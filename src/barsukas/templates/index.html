Barsukas

Multilingual Dictionary Editor for Language Learning

Barsukas is a database editor for building multilingual vocabulary content. It manages words (lemmas), their translations across multiple languages, example sentences, and audio pronunciations. Content created here is exported for use in the Trakaido language-learning app.

Key Features

Edit Dictionary Entries

Add and update words with definitions, parts of speech (noun, verb, etc.), and learner difficulty levels from 1 (beginner) to 20 (advanced).

Multilingual Translations

Manage translations across 9 languages including Chinese, Spanish, French, German, and Lithuanian. AI-assisted with human review.

AI-Powered Agents

Automated tools generate translations, verify quality, link sentences to vocabulary, and produce audio pronunciations.

Getting Started

Browse Content

Use the View menu to explore existing words, sentences, and conversations. Click any word to see its translations and related content.

Run Operations

Use the Tools menu to run AI agents, verify translations, review audio, and export data for the Trakaido app.
