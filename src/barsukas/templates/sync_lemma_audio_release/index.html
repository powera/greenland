Lemma Audio Sync

Sync approved lemma audio metadata between the release files (audio.jsonl under {{ release_dir }}) and the working database. Only the audio references (S3 URLs, status, md5) are synced — the mp3 bytes live on S3/CDN or under BARSUKAS_AUDIO_DIR, not in the release. Sentence audio is synced separately on the Sentence Sync page.

Keyed on (guid, language, voice, grammatical_form). "Exportable" means GUID-bearing, non-sentence audio in an approved status. "Changed" rows share a key but differ in a release-bearing field — an import would overwrite the database copy, an export the file copy.

Import: Release → Database

Read every audio.jsonl and upsert the audio rows into the database. Local review metadata (notes, quality issues, acceptance) on existing rows is preserved.

Export: Database → Release

Write approved lemma audio from the database out to the per-category audio.jsonl files, replacing their contents.
