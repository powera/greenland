Check Configuration

Validate corpus configurations without making any changes. Shows configuration status, file availability, and database state.

--check

Sync Configuration

Synchronize corpus configurations from config file to database. Adds new corpora, updates existing ones, and disables removed ones.

--sync-config

About database administration

This page runs maintenance operations against an existing database. Database creation is intentionally a repository-level script rather than an agent.

Typical Workflow:
  1. Check Configuration - Verify corpus configs are valid
  2. Sync Configuration - Update database with corpus definitions
  3. Load Corpora - Import word frequency data from corpus files
  4. Calculate Ranks - Compute combined frequency rankings
Command Line Usage:
PYTHONPATH=src python bootstrap_database.py --help
PYTHONPATH=src python -m storage.admin --help
