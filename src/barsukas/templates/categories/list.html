About the GUID System

Each lemma in the database is assigned a GUID (Globally Unique Identifier) based on its part-of-speech subtype. The GUID format is: 

<PREFIX>-<NUMBER>

For example:

  • N02-0001 - First animal noun (N02 = animal)
  • V01-0042 - 42nd physical action verb (V01 = physical_action)
  • A02-0007 - 7th color adjective (A02 = color)

The prefix letters indicate the POS type: N = Noun, V = Verb, A = Adjective, D = Adverb, Z = Numeral
