About WireWord Export

The WireWord export creates JSON files in the format expected by the WireWord API for language learning applications.

Export Types:
  • Default (recommended): Creates files in data/trakaido_wordlists/lang_XX/generated/wireword/:
    • wireword_levels_1_5.json, wireword_levels_6_10.json, etc. - Words and verbs split by difficulty level range
    • wireword_sentences.json - All sentences with level ≠ -1 and target language translation
    • wireword_manifest_v2.json - Manifest with MD5 checksums, level metadata, and file info
    This is what Trakaido expects.
  • Single File: Downloads a single JSON file with all words (or filtered subset)
