Note on multi-word phrases:
- Compound nouns that function as a single concept should be treated as a single lemma: "gas station", "ice cream", "living room", "fire truck"
- Adjective + noun combinations where the adjective is descriptive should be separate lemmas: "cotton shirt" → cotton (adjective) + shirt (noun), "red apple" → red (adjective) + apple (noun)
- When in doubt: if you could substitute a different adjective and the phrase still makes sense (cotton shirt → wool shirt), they are separate lemmas. If substitution changes the meaning entirely (gas station → diesel station doesn't work the same way), it's a single lemma.
