Slovenian nouns have three grammatical genders:
- Masculine: dom → domovi (house → houses), mož → možje (man → men)
- Feminine: žena → žene (woman → women), hiša → hiše (house → houses)
- Neuter: mesto → mesta (city → cities), okno → okna (window → windows)

Common plural patterns (nominative):
- Masculine: -i, -ovi, -je (dom → domovi, mož → možje)
- Feminine: -e (žena → žene, hiša → hiše)
- Neuter: -a (mesto → mesta, okno → okna)
- Some nouns are irregular

Note: Slovenian also has a dual number (for exactly two), but we only need
singular and plural forms here.
