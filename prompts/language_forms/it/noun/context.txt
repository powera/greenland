Italian nouns have grammatical gender (masculine or feminine) which determines the article:
- Masculine: il/lo (singular), i/gli (plural)
- Feminine: la (singular), le (plural)

Common plural patterns:
- Masculine -o → -i (il gatto → i gatti)
- Feminine -a → -e (la casa → le case)
- -e → -i for both genders (il cane → i cani, la chiave → le chiavi)
- Some nouns are irregular (l'uomo → gli uomini, il dito → le dita)
