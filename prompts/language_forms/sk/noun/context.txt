Slovak nouns have three grammatical genders:
- Masculine: dom → domy (house → houses), muž → muži (man → men)
- Feminine: žena → ženy (woman → women), ulica → ulice (street → streets)
- Neuter: mesto → mestá (city → cities), srdce → srdcia (heart → hearts)

Common plural patterns (nominative):
- Masculine animate: -i, -ia (muž → muži, priateľ → priatelia)
- Masculine inanimate: -y (dom → domy, strom → stromy)
- Feminine: -y, -e, -i (žena → ženy, ulica → ulice, kosť → kosti)
- Neuter: -á, -ia, -a (mesto → mestá, srdce → srdcia)
- Some nouns are irregular
